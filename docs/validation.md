# 测量记录（2026-10-22）

本文保留 2026-10-22 那次测量的数据。它描述该次运行，不代替 [ARCHITECTURE.md](../ARCHITECTURE.md) 里的当前结构。结构以源码为准。

基线为 `main@0e4ec82`。测量环境是 Unity 6000.6.0f1、URP 17.6.0、Burst 2.0.0、Collections 6.6.0、Mathematics 1.4.0、Apple M3 Max、Metal。工程为 Linear、1920×1080、render scale 1、MSAA 1、VSync 关闭。Unity 6000.0 的声明版本，以及 Windows、Android、D3D、Vulkan、GLES / OpenGL，不在这次测量里。

## 功能覆盖

临时场景为 2×2 相邻地形，每块五层，包含 Mask、非零 tileOffset、方向纹理和法线、连续 stochastic uv 与原始梯度。光照固定，相机做近、远和掠射飞行。参数为 pageCount 2048、pageTexels 256、border 4、poolSize 16、bakesPerRound 8、queueCapacity 512、queueTimeout 30。

每一格包含 BaseColor、BaseColorNormal、BaseColorNormalMask 三种层，共 72 档。每档三个窗口，每窗口预热 300 帧、采集 600 帧，共 194,400 个 Game 帧，运行错误为 0。另有 72 档近远画面自查，未见倒置、黑块或这次调度新增的明显页缝。12 张自查截图已逐张查看并删除。

| 压缩 | Bilinear | Trilinear | Anisotropic 4 | Anisotropic 16 |
|---|---|---|---|---|
| None | 3/3 | 3/3 | 3/3 | 3/3 |
| BC | 3/3 | 3/3 | 3/3 | 3/3 |
| ETC2 | 3/3 | 3/3 | 3/3 | 3/3 |
| ASTC 4×4 | 3/3 | 3/3 | 3/3 | 3/3 |
| ASTC 6×6 | 3/3 | 3/3 | 3/3 | 3/3 |
| ASTC 8×8 | 3/3 | 3/3 | 3/3 | 3/3 |

页方向、颜色、法线和 Mask 各通道用 GPU 解码对照。颜色在 Linear 工程中检查 sRGB。BC 颜色不使用 alpha，BC1 保持原有颜色端点精度。

分组与逐页顺序在六档压缩、三层、八个槽（含 border 与跨地形烘焙）上比较 10,036,224 个纹素，最大误差为 0。部分工作集、末尾一页、非零槽和覆盖有永久回归。

确定性三线性 / 各向异性保留原足迹、虚拟 mip 和长轴 taps。GPU 测试覆盖整数 mip、不同驻留页、相同祖先和域边缘。

时间 mip 在三线性、各向异性 4、各向异性 16 上，相对确定性过滤的实际 TAA 积累图 RGB MAE 为 0.000134 / 0.0000904 / 0.000101，P95 为 0.000525 / 0.000316 / 0.000349。图像是同一静止视角 33 帧平均、240×135 线性读值。这组数不覆盖运动内容的鬼影或噪声。

无 TAA、后处理关闭、动态分辨率、Scene 相机、MSAA 4、相机堆叠、零抖动、组件关闭和设置关闭时，时间 mip 保持关闭。重置历史和重启组件都先回到确定性过滤再恢复。两个 Game 相机（一个有 TAA，一个没有）的反馈轮转 189 / 188 次，后者没有打开时间 mip。压力条件包含相机启停、组件重建、4×4 小池、队列 32、超时 2 轮。

Frame Debugger 捕获到 `VT Bake Page`、`VT Encode`、`VT Indirect`、`VT Feedback`。第二个 Game 相机也有 Feedback。`R32_UInt` 反馈目标 60×34，与第二个相机 960×540 相符。回读不是可见 draw，其执行由回调和回归确认。

最终 C# / Burst 没有本包诊断。Metal 同步编译了 IndirectMap、TerrainBake 的两个 pass 乘三种层关键字，以及 TerrainLit_VT 的五个 pass（阴影、软阴影、洞、实例化、法线、雾、光照贴图的选定组合），147 次请求没有消息。六个 compute kernel 都实际执行。这是已覆盖的变体，不是全部关键字组合，也不是跨平台编译声明。

## 平台相关结论

| 项目 | 这次测量得到的结论 |
|---|---|
| UInt 块图复制到压缩 Texture2D | Metal 上五种压缩档成功。64 位颜色块为 `R32G32_UInt`，其余为 `R32G32B32A32_UInt`。源区域按块计，目标偏移按像素计。非零槽、边缘和重复写入通过。复制保留；当时的 Unity 没有暴露压缩资源别名 |
| `Apply(false, true)` 之后 Copy | Metal 通过。释放 CPU 可读副本后仍可 GPU 写入和重复覆盖，采样正确 |
| `R32_UInt` 异步回读 | 153 个不同 `PageId` 的全部 uint 位一致。实际 RenderGraph 场景持续产生反馈。旧回调不能清掉新请求的在途标志；销毁后不再提交 |
| GLES / OpenGL 的 y 方向 | 这次只确认 Metal 上的间接表方向和烘焙结果 |
| 外部资源与 RenderGraph | 持久物理图、scratch、块图均导入并声明访问。间接表在物理复制之后发布。连续帧内容和 Frame Debugger 一起作为依据 |
| 多 Game 相机 | 单请求通路、单在途回读。轮转和组件重建通过。时间参数按相机捕获。Scene 与 Reflection 保持生产者原有的材质策略 |

M3 Max 支持这次用到的全部压缩档，因此这次没有「硬件不支持」的失败样本。`CanCreate` 的格式检查仍然保留。其他硬件上的拒绝和回退需要在对应设备上测量。

## 时间

完整地形烘焙链：128 页、三层、相同生产者和资源。同一进程交替原逐页顺序与当时的调度，预热三次后各采 20 次。末尾 compute 读取三张最终物理图并回读同步，使计时包含实际写入完成。下表是 CPU 提交、GPU 工作和同步合在一起的墙钟时间，不是独立 GPU 时间，也不是整帧帧率。

| 格式 | 原顺序中位 / P95 ms | 当时中位 / P95 ms | 中位变化 |
|---|---|---|---|
| None | 23.077 / 24.657 | 23.063 / 27.626 | 同一路径，落在噪声里 |
| BC | 37.318 / 38.670 | 27.442 / 28.383 | 26.5% |
| ETC2 | 39.036 / 40.296 | 32.523 / 33.127 | 16.7% |
| ASTC 4×4 | 60.794 / 61.778 | 51.896 / 53.132 | 14.6% |
| ASTC 6×6 | 59.959 / 61.946 | 60.092 / 61.281 | 保持单页 |
| ASTC 8×8 | 71.401 / 72.238 | 71.470 / 72.697 | 保持单页 |

独立编码同样用输出依赖同步，128 页、20 次、高熵输入。ASTC 4×4 颜色 / 数据中位从 20.698 / 22.593 ms 到 12.953 / 14.241 ms。6×6 从 15.339 / 15.540 ms 到 12.733 / 12.857 ms。8×8 从 19.178 / 19.385 ms 到 16.318 / 16.853 ms。拟合迭代和模式未减少。ETC2 变化 alpha 的数据约 7.67 ms，没有显著变化。BC Mask 约 8.5 ms，这次未记成提速。

CPU 示例取 BC、三层、Trilinear 的第三个 600 帧移动窗口：

| 阶段 | 中位 µs | P95 µs | 口径 |
|---|---|---|---|
| Record | 6.583 | 29.792 | 每帧记录 marker |
| Decode | 37.999 | 55.124 | 172 个有任务的帧，各 worker 执行时间之和 |
| Collect | 72.292 | 86.917 | 同上 |

Job 数字是这些有任务帧上的执行时间之和，不是单次延迟，也不是等待时间。无任务帧没有并进平均值。整帧 GC 中位 34 B；禁用虚拟纹理的对照也是 34 B。观察到的增量为 0 B。这次没有拿到每条分配调用栈，因此不能把整个 Editor 的每帧分配写成 0 B。`supportsGpuRecorder` 为 false。有界 Metal capture 没有得到完整的分阶段 GPU 中位 / P95，Bake、Encode、Indirect、Feedback 的独立 GPU 时间这次空缺，不用墙钟或 0 填上。

## 内存

默认三层 PBR，物理图边长 4224，无 mip。单位 MiB。

| 格式 | 物理图逻辑字节 | Scratch 逻辑字节 | 块图逻辑字节 | Unity 对象统计 |
|---|---|---|---|---|
| None | 204.1875 | 0.7976 | 0 | 204.1910 |
| BC | 42.5391 | 3.1904 | 0.6647 | 85.0810 |
| ETC2 | 42.5391 | 3.1904 | 0.6647 | 85.0810 |
| ASTC 4×4 | 51.0469 | 3.1904 | 0.7976 | 102.0966 |
| ASTC 6×6 | 22.6875 | 0.7976 | 0.0295 | 45.3779 |
| ASTC 8×8 | 12.7617 | 0.7976 | 0.0166 | 25.5263 |

ASTC 查找表另有 9,128 B。页目录 5,592,405 项 × 4 B = 22,369,620 B，目录结构另 88 B。Unity 对压缩 Texture2D 的对象统计约为逻辑字节的两倍；这个计数不等于驱动实际驻留，也不能据此判断存在 CPU 可读副本。Apple 统一内存的实际驻留量这次没有取到。相对当时旧的 BC3 / ETC2 RGBA 全层预算，按层格式使单颜色少 50%，颜色加法线少 25%，三层少 16.7%。分组工作集是有界的若干 MiB，没有整张物理 RenderTexture 的中间副本。

## 记录边界

测量时的代码在 main 上，没有推送、PR 或新分支。测试纹理、反馈、间接表和编码结果只在内存中读取。Profiler 有界，Deep Profile 关闭，没有构建 Player。

临时宿主（文件合计 1,308,248,552 B）、日志、XML、脚本、截图和捕获在测量结束后删除。另删除该轮 21 个宿主外辅助文件和 10 个已确认的未跟踪 AppleDouble 副文件。用户的 Unity 缓存和其他 Editor 未清理。Git 对象目录里原有的 AppleDouble 索引副文件保留。删除释放的是容量，已经发生的 SSD 写入还在。

这次没有覆盖：其他平台和 Unity 6000.0 的实测、运动内容的长期 TAA 统计、XR、独立 GPU pass 的完整计时、严格的 GC 调用栈，以及驱动驻留显存。硬件各向异性候选已从公开设置中移除。
